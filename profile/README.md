# BugBotLab

BugBot is a small robot for learning real robotics: a camera, a depth sensor, an inertial sensor and an optical-flow sensor on a three-board stack that slides across its mat on vibration motors, programmed in Python. The same program runs on the robot or in the simulator in your browser.

- Lessons with the simulator in every step: [bugbotlab.com/bugbot-lessons](https://www.bugbotlab.com/bugbot-lessons/)
- Docs: [bugbotlab.com/bugbot-docs](https://www.bugbotlab.com/bugbot-docs/)
- For schools: [bugbotlab.com](https://www.bugbotlab.com/#schools)

## Open source

| Repository | What it is |
|---|---|
| [bugbot-firmware](https://github.com/BugBotLab/bugbot-firmware) | the robot's C firmware with its Python layer, and the dongle firmware |
| [bugbot-hardware](https://github.com/BugBotLab/bugbot-hardware) | schematics, bill of materials, 3D models, assembly, and the circuit simulation of the stack |

Both are MIT licensed. The PCB layouts are not published. The lessons, the simulator and the teacher tools are free to use online.
